# Security Policy

This repository holds a demonstration and a network recipe for local development;
it is not meant to be deployed. The component that enforces the registry's rules is
the chaincode, [`fabric-vdr-core`](https://github.com/snktibor/fabric-vdr-core).

Please report vulnerabilities in either repository **privately**, as described in
[`fabric-vdr-core`'s security policy](https://github.com/snktibor/fabric-vdr-core/blob/main/SECURITY.md),
and not through public issues, discussions or pull requests.
